# **Introduction to package.json** #

- *package.json()* is a configuration file used in Node.js projects.
- It contains metadata about the project and information on project dependencies.
- Go to your projcet folder and use npm init to initialize the project or to create package.json.
- Name, Version, Description ("name", "version", "description");
1. Specifies the name and version of the project.
1. Helps uniquely indentify and version the project.

- Entry Point ("main"):
1. Specifies the main entry point file for the application.
- The file executed when the application starts.

- *Scripts:*
1. Contains custom scripts for various tasks (e.g., running tests, starting the server)
- *Author, Licence, and More:*
- Information about the project's author, license, repository, and other metadata.
- Useful for documentation and collaboration.

*note:* You can also use npm init-y to create package.json quickly.
