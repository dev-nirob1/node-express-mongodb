# Installing Node.js and npm (FNM)
- **FNM (Fast Node Manager):** is a command-line utility that enables developers to easily manage and switch between different versions of Node.js on their machines.
- **FNM works across multiple platforms and is known for its speed and simplicity
- If you don't have winget on Windows, then you can also use chocolatey, or scoop to install FNM. Of Cource, you need to install chocolaty or scoop first.

# Simple Installation
- Just go to node.js official website and choose operating system and download and install.

# Installing FNM 

- **Option-1:** Using Winget
- To Install FNM using Winget: 

 ```
  winget install fnm
 ```
- **Option-2:** Using Chocolatey
 ```
 choco install fnm
 ```
 - **Option-3:** Using Scoop
 ```
 scoop install fnm
 ```
*note:* For choco and scoop, You need to install chocolatey of scoop first.

# Why Use FNM?
- **Speed:** Faster than other Node.js version managers like NVM.
- **Lightweight:** Minimal resource usage.
- **Cross-platform Support:** Works on Windows, macOS, and Linux.
