# Challenge - 1 #
- Challenge: 'Event Maestro: handle it all'

- Create a program using Node.js EventEmitter that: 
1. Listens for multiple types of user events (e.g., login, logout, purchase, and profile update).
1. Tracks how many times each event is emitted.
1. Logs a summary of all event occurrences when a special summary event is triggered.

**Requirements**
1. Create at least four custom events (e.g., user-login, user-logout, user-purchase, profile-Update)
1. Emit these events multiple times with different arguments (e.g., username, item-purchased).
1. Track and store the count of each event type.
1. Define a summary event that logs a detailed report of how many times each was triggered.
